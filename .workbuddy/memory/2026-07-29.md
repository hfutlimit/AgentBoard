## 修复生产环境 Mermaid 图表不渲染 (2026-07-29 10:47)
- **现象**：http://124.220.44.12/documents/5 中 Mermaid 代码块显示为纯文本，未渲染为 SVG。
- **根因**：IIS 部署包 `dist/agentboard-web/` 缺少 `/static/mermaid.min.js`。`scripts/package_windows.py` 优先使用 `frontend/dist/frontend/browser/`，而 `mermaid.min.js` 仅放在 `agentboard/web/static/`，导致打包时遗漏。IIS 的 SPA fallback 将 `/static/mermaid.min.js` 重写为 `index.html`（Content-Type: text/html，4430 字节），`enhanceMermaid()` 加载失败，降级为原始代码块。
- **验证**：
  - `curl -I http://124.220.44.12/static/mermaid.min.js` 返回 `text/html` + 4430 字节（实为 index.html）。
  - 本地 `http://127.0.0.1:8080/static/mermaid.min.js` 返回 `application/javascript` + 2571838 字节，Playwright 验证本地 `/documents/17` Mermaid 可正常渲染为 `.mermaid-svg`。
- **修复**：将 `agentboard/web/static/mermaid.min.js` 复制为 `frontend/public/static/mermaid.min.js`，纳入 Angular assets。`npm run build` 后 `browser/static/mermaid.min.js` 生成，打包脚本自然包含。
- **构建与提交**：
  - `npm run build`(node 22.22.2) → `main-HOVDWMH3.js` / `styles-DRM33VRW.css`。
  - 产物同步到 `agentboard/web/static/`；运行 `scripts/package_windows.py` 生成新的 `dist/agentboard-web.zip`。
  - 提交 `frontend/public/static/mermaid.min.js` + build 产物：`fix(web): 将 mermaid.min.js 加入 Angular public assets，修复 IIS 部署后 Mermaid 图表不渲染` → push origin main。
- **后续动作**：需在生产服务器 IIS 站点物理路径重新解压 `dist/agentboard-web.zip`，覆盖旧静态文件。线上即可通过 `/static/mermaid.min.js` 正确加载 mermaid。
