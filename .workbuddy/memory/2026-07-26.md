## 可复用经验
- **本地 E2E web 验证**：若 8080 web 的 `AGENTBOARD_API_URL` 与实际 API 端口不符（登录被拒/ERR_CONNECTION_REFUSED），最干净做法是在新端口起一个 web_app.py（带正确 `AGENTBOARD_API_URL` + 同 static 目录），不扰动既有 8080 服务。
- **回归核对技巧**：用 `git stash` 还原改动→重建原始包→跑同一 E2E，可 100% 区分「本次改动引入」与「既有缺陷」，避免误报回归。注意 `cp dist/.../browser/. dest/` 需加 `-r`，否则子目录（assets）会被跳过、且可能因末尾 `/.` 语法报 "omitting directory"。
