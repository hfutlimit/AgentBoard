Proposal · P-0042

看板任务批量导入与字段映射

Proposal 正文（点击收起 / 展开）

背景

团队从旧工单系统迁移到 AgentBoard 时，需要把存量任务批量导入到指定看板。当前只能逐条创建，200+ 任务的迁移成本过高，阻塞了两个团队的切换计划。

目标

  • 支持上传 CSV / JSON 文件批量创建任务
  • 提供字段映射界面：源字段 → 看板字段
  • 导入前可预览与校验，导入后生成导入报告

初步方案

导入流程拆为三步：上传解析 → 字段映射 → 预览提交。映射配置可保存为模板复用：

mapping:
  title:    "$.summary"
  assignee: "$.owner.email"
  priority: "$.p_level"   # P0-P3 → high/mid/low
  sprint:   "$.milestone"

暂不考虑

  • 附件与评论的迁移
  • 与旧系统的双向实时同步
