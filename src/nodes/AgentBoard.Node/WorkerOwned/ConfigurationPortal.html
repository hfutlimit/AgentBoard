添加 Agent

先填写基本信息并保存到本机，再配置工作类型、CLI 和提示词。新实例默认停用，不会领取任务。

新增项目目录

选择项目并填写本机工作目录。确认后，点击页面右上角「保存本机配置」写入文件，重启执行 Worker 后生效。
