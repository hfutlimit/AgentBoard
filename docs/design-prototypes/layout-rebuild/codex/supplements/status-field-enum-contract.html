契约 1 · 统一 status → tone 映射（单一事实来源）

原型 badgeTone() 把「进行中/已通过/已完成/Active」全塞进 green，且中文英文混用。下方用语义 tone（非颜色名）作为稳定键，原型展示层与 Angular 落地层共用同一张表。tone 取值限定 5 个：greenambergrayredblue，与优先级语言（priority-language.html）共用同一套语义色，避免新增主色。

落位说明 · 改写原型 badgeTone 的参考实现

下为 Story 316 落地时替换 badgeTone()（html:1356）的参考片段——用一个只读映射表取代分支判断，原型与 Angular 共享同一 JSON：

参考STATUS_TONE = { in_progress:'green', done:'green', approved:'green', active:'green', in_review:'amber', discussing:'amber', invited:'amber', planned:'gray', backlog:'gray', draft:'gray', blocked:'red', scheduled:'blue' };
const badgeTone = status => STATUS_TONE[status] || 'gray';

约定：tone 与 priority 共用 5 个语义色（green/amber/gray/red/blue），不为状态新增第六种色。优先级用 red/amber/blue/gray（priority-language.html），状态用 green/amber/gray/red/blue（本表），二者色域重合但语义正交，规范上可接受。
