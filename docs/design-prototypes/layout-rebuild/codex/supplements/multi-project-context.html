补充 1 · 钉住项目标签条（替代「返回首页→重进」）

原型在 enterWorkspaceButton 点击后把 homeShell.hidden=true、projectWorkspace 显示（html:1540-1546）。工作台内仅有单项目切换弹层（projectSwitcher），无「保留多个已开项目」的常驻入口，跨项目对比必须先回首页。
下方用常驻标签条承载「最近/钉住的项目」，点击即切换且保留各自路由与滚动（解决 AB-239），不必回到 Home Shell。
