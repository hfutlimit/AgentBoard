PRP-31 · Agent 一次性 Enrollment Key

由 Rebecca 发起 · 限制长效 Key 的共享与身份漂移

提案描述

当前 API Key 为长效凭证，存在共享与身份漂移风险。本提案建议引入一次性 Enrollment Key：Worker 首次注册时用 Enrollment Key 换取绑定 Agent 身份的短期凭证，长效 Key 不再直接用于身份。

# Enrollment 流程
enroll(enrollment_key) -> (agent_id, short_lived_token)

讨论收敛后由 Owner 批准，进入执行阶段并保留全部讨论证据。
