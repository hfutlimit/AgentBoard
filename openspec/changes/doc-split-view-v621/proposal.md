# Proposal: 文档详情三视图 + 新标签页

**状态**: accepted
**日期**: 2026-08-12

## 需求

1. 文档列表点击新标签页打开（已有部分实现）。
2. 详情页三种视图：完全预览 / 分屏编辑 / 分屏只读，可切换。
3. 主题切换 toggle（全局复用）。
4. 编辑文档元数据弹窗（除内容外全部信息）。
5. 所有「丢弃未保存改动」确认使用自定义弹窗，禁用原生 confirm。
6. 列表项 tooltip 展示完整文档名。

## 决策

- 三视图状态用 `docViewMode` 信号，模板 `@switch` 渲染；
- 分屏同步滚动按高度比例联动；
- 元数据编辑复用既有 `openDocModal('edit')`；
- 主题切换复用全局 `toggleTheme()`；
- 确认弹窗复用 `.modal-overlay` 模态体系（自定义组件，非原生 confirm）。

## 影响

纯前端改动，不触碰后端契约。
