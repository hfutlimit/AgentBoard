# Proposal: 看板视图列全折叠/全展开 (v6.0)

## 问题
看板视图（v5.8 引入）按 7 个状态分列，已完成任务常驻「完成」列。当任务量大时，
逐列点击折叠（v5.8 单列折叠）操作繁琐，缺少一键「全部折叠 / 全部展开」能力。
列表视图（v1.9）已有分组一键全折叠/全展开，看板视图应提供对称体验。

## 方案
在看板视图工具栏新增一个仅看板模式可见的「全折叠 / 全展开」切换按钮，复用既有
`collapsedColumns` 信号与 `toggleColumnCollapse` 基础设施，对 7 个状态列批量置位/清空，
并通过 `localStorage.agentboard_collapsed_cols` 持久化（与单列折叠同源）。

## 范围
- 纯前端，零后端契约变更。
- 不改动拖拽改状态、批量选择等现有看板行为。
