# Proposal: 命令面板接入后端搜索 — Epic 69 v5.6

## 问题
v5.4 命令面板仅覆盖静态命令 + 最近访问项目，无法按关键词检索全站任务/项目。用户想跳转到某个具体任务或项目时，仍需先进入对应列表再翻找，效率低。

## 目标
命令面板输入查询时，实时接入后端搜索：
- **任务搜索**：`/api/tasks?q=` 跨可见项目检索任务标题，结果以「任务」分类标签呈现，点击跳转到 `/task/{id}`。
- **项目搜索**：客户端基于已加载的 `projects()` 按名称/key 过滤，结果以「项目」分类标签呈现，点击跳转到 `/project/{id}`。
- 命中静态命令时命令优先（保持 `Enter` 执行命令的既有行为），后端实体结果作为补充列于其后。
- 200ms 防抖、搜索中指示器、无匹配空态。

## 范围
- 纯前端，零后端契约变更（复用既有 `/api/tasks?q=` 与 `projects()` 信号）。
- 不改动 v5.4 命令面板的既有命令与快捷操作。

## 非目标
- 不接入 Story/文档后端搜索（本迭代聚焦任务/项目）。
- 不做搜索结果分页/虚拟滚动（limit 控制在 10 任务 + 8 项目）。
