# Proposal: 筛选预设默认加载自动应用 (v4.6)

## 问题
v4.0 已支持多命名筛选预设 + 默认预设（星标默认、一键「应用默认」），但默认预设仅在用户手动点击「★ 应用默认」时才生效。应用加载后仍需手动操作，未体现「默认」语义，体验不完整。

## 方案
在 App 组件 `ngOnInit` 初始化阶段，若已存在默认预设（`defaultPreset()` 非空），自动调用既有 `applyDefaultPreset()` 应用之。用 `defaultPresetApplied` 标志保证仅执行一次，避免随路由切换重复应用而覆盖用户的手动筛选。

## 影响
- 纯前端，零后端契约变更。
- 仅影响初始加载时的筛选状态；进入具体 story / task 视图后默认预设立即生效。
- 不破坏「手动清除 / 切换筛选」行为，手动操作仍可随时覆盖。

## 验收
- 将某状态筛选存为默认预设 → 刷新页面 → 该状态 chip 自动处于激活态、任务列表按预设收窄。
- 无默认预设时，加载行为与现有一致（无任何副作用）。
- 0 pageerror / console / .js+.css 404（Playwright 验证）。
