# Proposal: 命令面板 (Ctrl/Cmd+K) — Epic 67 v5.4

## 问题
任务列表与全局导航缺乏统一、键盘优先的快捷入口。用户需多次点击才能跳转项目/视图或执行常用操作（新建、切换密度、导出等），效率低于 Linear / Jira 等现代工具。

## 目标
新增一个全局命令面板：`Ctrl`/`Cmd` + `K` 打开，输入即过滤，方向键 + `Enter` 执行，覆盖：
- 导航：首页 / 项目列表 / 文档中心 / 设置
- 新建：任务 / Story / Epic（基于当前上下文）
- 视图操作：切换行密度、打开快捷键帮助、导出当前任务列表 CSV
- 动态：最近访问的项目（复用 `recentProjects` 信号）

## 范围
- 纯前端，零后端契约变更（不新增/修改任何 API）。
- 不改动既有快捷键（v2.2 热键、v4.5 抽屉导航等）行为。

## 非目标
- 不接入后端全文搜索（本迭代仅静态命令 + 最近项目）。
- 不做命令分组/分类折叠（保持单列列表，聚焦核心动作）。
