# Proposal: 看板视图列内按维度子分组 (Epic 74 v6.1)

## 问题
看板视图（v5.8）按 7 个状态列分桶，已支持拖拽改状态、列折叠、卡片批量选择。
但列内卡片始终是**平铺**的——与列表视图已具备的「按类型/优先级/负责人/截止日期分组」能力不对称：
用户切到看板后，无法在同一状态列内按维度快速聚拢卡片（例如把 in_progress 列的「高优先级」任务集中到顶部）。

## 目标
在看板视图内复用列表已有的 `taskGroupBy` 分组选择器与 `groupLabel` 分桶逻辑：
1. 每个状态列内按所选维度（type / priority / assignee / due）划分子分组。
2. 子分组头显示维度标签 + 计数徽章（sticky）。
3. `taskGroupBy='none'`（或 `'status'`）时退化为当前平铺行为，零回归。
4. 状态列仍为拖拽主轴（拖拽目标 `.kanban-col-body` 不变），列折叠不变。

## 非目标
- 不改动后端契约（`groupLabel`/`dueBucket`/`priorities` 全部复用既有）。
- 不改变看板「列=状态」的主轴语义（拖拽改状态保持有效）。
- 不在看板内新增独立分组选择器（直接复用共享工具栏的「分组」下拉）。

## 风险
低。纯前端、零契约变更；`boardSubGroups()` 与 `groupedTasks()` 共用同一套分桶逻辑，行为一致。
